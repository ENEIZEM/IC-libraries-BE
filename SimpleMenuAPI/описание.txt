Элемент	            Кнопки                     Back            Тап снаружи         Commit

Меню без кнопок       —	                       close	          close	          реактивно
Меню с кнопками	    positive + negative	    отмена (rollback)	   ❌	        по positive
Диалог          	positive + negative	    отмена (rollback)	   ❌	        по positive
Hint	              —	                       close	          close            нечего

Нет кнопок:
  → реактивное
  → Back: close
  → тап снаружи: close
  → кнопок нет — пользователь выходит любым способом

Есть кнопки:
  → транзакционное
  → positive + negative обязательны (явная альтернатива)
  → neutral опционален
  → Back: отмена (rollback + наследует negative.onClick)
  → тап снаружи: выключен
  → изменения применяются только по positive

Валидация:
  только positive без negative → ОШИБКА (нет явной альтернативы)
  только negative без positive → ОШИБКА (нечего commit'ить)
  нейтрал без пары positive/negative → ОШИБКА

Всегда транзакционные.
Всегда:
  positive + negative обязательны
  neutral опционален
  Back: отмена (rollback + наследует negative.onClick)
  тап снаружи: выключен
  изменения применяются только по positive

Валидация:
  нет positive → ОШИБКА
  нет negative → ОШИБКА
  есть только neutral → ОШИБКА
