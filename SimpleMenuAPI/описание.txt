Общие:
	type - Тип элемента. (divider, button, switch, checkbox, edittext, selection, multiselection, seekbar)
	name - Название элемента.
	textSize - Размер текста.
	hint - Текст подсказки..
	hintColor - Цвет подсказки. Пример: "#ffaaff".
	hintSymbol - Символ подсказки. Пример: "@".
	hintButtonText - Текст кнопки закрытия диалогового окна.

Другое (Для разных элементов):
	enableScrolling - Включить прокрутку текста в кнопке элемента. Пример: false.
	state - Состояние переключателя. Пример: true.
	buttonText - Текст кнопки элемента.
	colors - список двух или более цветов. Пример: [Color.RED, Color.BLUE, Color.BLACK]. Для одинакового цвета: [Color.RED, Color.RED].
	edittextHint - Подсказка для текстового поля.
	edittextCurrent - текущий текст для текстового поля
	edittextLinesCount - Максимальное количество линий для текстового поля. Пример: 2.
	seekbarMin - Минимальное значение для ползунка.
	seekbarMax - Максимальное значение для ползунка.
	seekbarCurrent - Текущее значение ползунка.

Функции (Для разных элементов):
